A complete educational platform built solo: courses, multiplayer 3D world, RPG-style gamification, an AI assistant with its own memory and an admin panel — all in React + Supabase.
The dashboard unifies tasks, projects, exams and quests into a single actionable feed — before, each system lived on its own page and the student had to check them one by one.
The 3D campus (Three.js) isn't just aesthetics: it moves social interaction and quests out of the flat browser, with live voice, AI NPCs and mini-games — the bet is that teaching feels less like an LMS and more like a shared world.
2D version (Phaser) of the same world, for those without hardware for 3D — synchronized with the VR campus via Supabase Realtime.
Live classes have an ephemeral chat, a text-to-speech queue and a PDF summary generated when the session closes, so something tangible remains without depending on a recording.
Each course's content lives in Supabase, not hardcoded in the bundle — a teacher can edit a class without touching code or redeploying the site.
Custom admin panel: account approval, task grading, exam generation, live control of the VR world — built to measure instead of a generic CMS.
XP/level achievement system in RPG style: the idea is that finishing a course feels like character progress, not a checked box.
